# Дизайн и стайлгайд

## Обзор дизайна

AuthApp использует современный минималистичный дизайн с тёмной темой и голубыми акцентами. Приложение полностью адаптивно и оптимизировано для всех размеров экранов.


## Расстояния (Spacing)

Используется система 4px grid:

```
xs   = 4px
sm   = 8px
md   = 12px
lg   = 16px
xl   = 24px
2xl  = 32px
3xl  = 48px
4xl  = 64px
```

Применяется через Tailwind классы:
- `p-4` = 16px padding
- `gap-4` = 16px gap
- `mb-8` = 32px margin-bottom

## Радиус углов

```
xs   = 2px  (для малых элементов)
sm   = 4px  (для текстовых полей)
md   = 6px  (для кнопок)
lg   = 10px (для карточек)
xl   = 16px (для контейнеров)
```

## Анимации и переходы

### Основные переходы

```css
/* Быстрые переходы */
transition: 150ms ease;

/* Средние переходы */
transition: 300ms ease;

/* Медленные переходы */
transition: 500ms ease;

/* Используемые для */
- bg-color: 150ms
- color: 150ms
- border-color: 150ms
- transform: 300ms
- opacity: 200ms
```

### Анимации

```css
/* Spin (для загрузки) */
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
animation: spin 1s linear infinite;

/* Pulse (для активных элементов) */
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
animation: pulse 2s cubic-bezier(0.4, 0, 0.6, 1) infinite;

/* Fade in */
animation: fadeIn 300ms ease-in;
```

## Доступность (A11y)

### Цветовой контраст

- Фон #0f1117 + Текст #e6edf3: Ratio 14.8:1 ✅
- Акцент #58a6ff + Текст #0d1117: Ratio 7.4:1 ✅
- Все комбинации соответствуют WCAG AA стандарту

### Клавиатурная навигация

- Tab: Переход между элементами
- Enter/Space: Активация кнопок

### Screen readers

- Все иконки имеют ARIA labels
- Формы помечены правильно
- Заголовки используют правильную структуру

## Рекомендации для разработчиков

### Когда добавлять новые компоненты

1. Используйте готовые компоненты из `components/ui/`
2. Соблюдайте цветовую палитру
3. Используйте Tailwind классы из системы spacing
4. Добавьте анимации через transition классы
5. Проверьте адаптивность на мобильных

### Принципы дизайна

1. **Минимализм**: Удаляйте ненужные элементы
2. **Контрастность**: Используйте цвета для выделения важного
3. **Пространство**: Используйте белое пространство эффективно
4. **Консистентность**: Соблюдайте единый стиль
5. **Доступность**: Тестируйте с экранными читалками

## Файлы для изменения стилей

Глобальные стили находятся в:
```
/app/globals.css
```

Здесь определены:
- Css переменные для цветов
- @theme конфигурация для Tailwind
- Base стили
